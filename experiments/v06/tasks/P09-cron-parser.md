Build a cron expression parser CLI in Python. Parse standard 5-field cron expressions (minute, hour, day-of-month, month, day-of-week) supporting *, lists, ranges and steps, and month/day names. Subcommands: validate <expr> (explains each field or reports the error) and next <expr> [-n N] (prints the next N run times from now). Handle invalid dates such as February 30. Single file cron_parser.py, stdlib only.
